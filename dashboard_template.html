Self-Agent vs. Therapist Baseline

Ten simulated personas, each scored against a validated set of DSM-5-TR personality-disorder ground truths. Two raters assessed every case independently: the multi-agent self-simulation (ensembled ×3 report samples) and a single-pass licensed-therapist-style baseline reading the same case material.

Per-case likelihoods

For each persona: every disorder either rater assigned meaningful probability to, plus any ground-truth disorder that was missed entirely (shown at 0%). Bars are each rater's own likelihood estimate (0–100%), not normalized against each other.

Case-level scoring summary

GTLS = mean likelihood the rater assigned across the true ground-truth disorder(s) for that case (higher is better). Brier = mean squared error of that rater's full probability vector against the true labels (lower is better). Top-1 = whether the rater's single highest-probability disorder matched a ground-truth disorder.

Self-agent: n_repeats=3 report ensembling per case, single round of therapist↔self dialogue. Therapist baseline: single independent read of the same case, scored on the same 10 in-scope DSM-5-TR personality disorders.
